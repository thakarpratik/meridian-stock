# Meridian

Daily stock desk. It opens on five pullbacks you can enter. Each card has a trigger, an invalidation, and a target.

Levels are set from the last completed daily close and stay put through the session. A buy means the live price is inside the pullback zone. Quiet names, penny stocks, and parabolic spikes stay off the list.

## Run

Requires Node.js 22.

```bash
npm install
npm run dev
```

Then open the local address printed by the dev server.

Prices come from Yahoo Finance when the site is open. This is a checklist, not a broker and not advice.
